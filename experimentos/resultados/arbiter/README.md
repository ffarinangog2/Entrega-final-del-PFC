# Evidencia ARBITER E4

Este directorio está reservado para ejecuciones reales en la VM experimental.
Actualmente existen **0 de 130 corridas**. Los tests unitarios no constituyen
evidencia experimental.

- `raw/`: manifiesto JSON por corrida.
- `oracle/`: resultado del oráculo por corrida.
- `summary/`: agregados y comparaciones pre-registradas.
- `analysis/`: diagramas de caja y tablas estadísticas.
- `SHA256SUMS`: se genera después de conservar toda la evidencia; no sustituye
  ni modifica `experimentos/resultados/SHA256SUMS`.
